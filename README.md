# Wiki Agent

Claude Code and Codex plugin for the lab wiki. It lets agents search, read, and
write shared Markdown knowledge pages through an MCP server backed by semantic
embeddings.

## Install

### Prerequisite: uv

The plugin starts its MCP server with `uv tool run` from this repository's
`main` branch, so `uv` must be installed and available on your `PATH` before
Claude Code or Codex starts the plugin.

Common install options:

```bash
brew install uv
```

or:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

After installing `uv`, restart Claude Code or Codex so the plugin process
inherits the updated `PATH`.

### Claude Code

Install in Claude Code:

```text
/plugin marketplace add william-dawson/l_sim-wiki-agent
/plugin install wiki@wiki-marketplace
/reload-plugins
```

### Codex

Install in Codex:

```bash
codex plugin marketplace add william-dawson/l_sim-wiki-agent
```

Then open `/plugins`, install `wiki`, and start a new thread so the MCP tools
and skill are loaded.

## Configuration

The MCP server uses SSH to clone, pull, and push the wiki repository. Before
starting Codex or Claude Code, make sure your normal GitLab SSH setup works:

```bash
ssh -T git@gitlab.com
```

The default wiki remote is:

```bash
git@gitlab.com:wddawson/l_sim-agent-wiki.git
```

Override it only if the wiki repository moves:

```bash
export WIKI_REMOTE=git@gitlab.com:group/project.git
```

`GITLAB_PROJECT` can also be set to build the default SSH remote:

```bash
export GITLAB_PROJECT=wddawson/l_sim-agent-wiki
```

The wiki repository must contain an `embeddings.db` generated by `wiki-reindex`.
GitLab CI is configured to regenerate and commit that database when Markdown
pages under `docs/` change.

## Plugin release checklist

Every committed plugin change must update the plugin version in
`plugins/wiki/.claude-plugin/plugin.json`. Codex and Claude Code cache installed
plugins by version; if the version stays the same, users can keep running an
older cached copy even after `main` has new commits.

After changing the plugin:

1. Update `plugins/wiki/.claude-plugin/plugin.json`.
2. Commit and push the change.
3. Reinstall or update the plugin.
4. Start a new thread so the MCP tools and skill are loaded from the updated
   plugin.
